# DemoExam

A WPF and SQL Server information system for a shoe store, featuring authentication, role-based access, catalog management, and order CRUD.

## Technology

.NET / C#, SQL

## Repository layout

Primary areas: `docs/`, `ObuVApp/`.

## Build and verification

```powershell
dotnet build ObuVApp/ObuVApp.csproj -c Release
```

Exact requirements may vary by platform. Check project-specific documentation and configuration before building.
